# PEC 1
_Despligue y escalabilidad_

## Objetivos
Esta PEC consolida lo aprendido de versionado de código, Docker y Kubernetes.

Dominando estas tecnologías, se consigue asentar la base de las buenas prácticas e infraestructura MLOPS.

## Se Pide
* Script Python que cuente números del 1 al 10.
* Usar un Dockerfile para crear una imagen Docker que pueda ejecutar ese script.
* Levantar el contenedor con Kubernetes con un número de al menos 3 réplicas.
* Cada uno de los pasos debe estar versionado y deben ser commits independientes utilizando un repositorio remoto en Github.

## Fecha de Entrega
6/12/2026

## Entrega de nota
13/12/2026

## Evaluación
La PEC tendrá un peso del 30% sobre la nota, teniendo el primer enunciado el valor de 1 punto y el resto de 3 puntos, la nota máxima será de un 10.

La entrega debe ser en formato PDF con capturas de cada uno de los pasos y el link al repositorio (el repo debe ser público para que lo pueda visualizar).
